# 探栏

中文名：**探栏** · 前缀 `probe` · 端口 **8100**

## 骨架（新骨）

**传感报文装载 → 标定/质控门槛入栏 → 站点汇总物化 → 坏点旁路 → 栏账互证**

| 对比 | 潮切 | 对拍 | **本仓** |
| --- | --- | --- | --- |
| 拓扑 | 事件时入窗→关窗 | 双轨对齐 | **质控门槛入栏→站点汇总** |
| 在途 | 入窗缓冲 | 悬账 | **入栏缓冲（过门槛未汇总）** |
| 产物 | 窗切片 | 对齐差+结论 | **站点汇总账** |
| 旁路 | 迟到匣 | 悬账缺边 | **坏点匣（未过门槛）** |

皮：环境监测传感站（大气/水质探头）。去皮：**标定质控门槛 + 入栏 + 汇总物化 + 坏点旁路 + 栏贯验**。  
禁止做成运维工单、告警大屏、传感器 CRUD。禁止抄潮切窗号/对拍左右轨命名。

## 固件门禁（凭证表 + 只读归档）

低版本固件探头不得进现行入栏。工程形态：`固件白名单史` 记每次白名单变更的「最低版本 + 指纹」，低版本设置被拒（不可回刷）；低版本报文进 `固件归档`（只读），现行 `入栏缓冲` 只收达标固件集（行上带白名单指纹）。

- 门禁账：`GET /api/固件门禁`、`GET /api/固件门禁/对账`、`GET /api/固件门禁/站点源对账`、`GET /api/固件门禁/归档`
- 运维动作：`POST /api/固件门禁/白名单`（抬升最低版本）、`POST /api/固件门禁/探头`（登记站点固件）
- 页面可见：探栏台 · 站点源 · 报文流 · 入栏缓冲 · 坏点匣
- 夹具复现：登记低版本探头（如 `站-河东` → `1.0.0`）后灌 `低固件样例`；低版本入只读归档，现行入栏不增。
- 边界：既未署固件、站点也未登记的存量报文按兼容放行（明细里以 `未署入栏笔数` 计数提示，不判红）；只有「低于白名单」或「灯红站点仍有入栏」判红。
- 并发脚本：`python3 backend/scripts/固件门禁并发.py`（改白名单瞬间并发灌入不得漏拦）
- 测试：`backend/tests/test_fwgate_1.py`（失败测甲）· `test_fwgate_2.py`（失败测乙）· `test_fwgate_3.py`（争用）
